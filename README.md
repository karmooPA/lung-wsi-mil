# Lung WSI MIL

MIL-based whole-slide image analysis for lung tumor detection.

## Current Task

Binary classification of lung pathology whole-slide images:

- Tumor
- Normal

## Planned Pipeline

WSI  
→ Tissue Detection  
→ Patch Extraction  
→ Pathology Encoder  
→ Patch Embeddings  
→ Attention MIL  
→ Tumor / Normal Classification  
→ Attention Heatmap
