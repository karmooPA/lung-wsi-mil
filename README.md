# Lung WSI MIL

MIL-based whole-slide image analysis for lung tumor detection.

## Current Task

Binary classification of lung pathology whole-slide images:

- Tumor
- Normal

## Reference Study

Afonso et al. (2024)

**Multiple Instance Learning for WSI: A Comparative Analysis of Attention-Based Approaches**

Journal of Pathology Informatics.

## Planned Pipeline

WSI  
→ Tissue Detection  
→ Patch Extraction  
→ Pathology Encoder  
→ Patch Embeddings  
→ Attention MIL  
→ Tumor / Normal Classification  
→ Attention Heatmap
